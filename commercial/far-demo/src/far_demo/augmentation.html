What this instrument can and cannot establish

Structural prompts document omissions. Optional model-generated critiques interpret the meaning of supplied text but are unverified hypotheses. Neither lane proves source accuracy, formal validity, nor human learning. SHA-256 supports local integrity checks, not authentication. This prototype stores sessions in this browser and transmits input to the demo server for processing; infrastructure logs and browser storage may still expose sensitive text. Do not enter secrets.

This is an experimental application beside FAR's accepted contracts, not a conforming FAR-ELENCHUS session or a validated cognitive diagnosis. No external human-effectiveness study has been completed.
