# FAR-REPLAN-001 candidate evidence replay

**Status: Research utility / no scored inference established.** This offline tool audits the structural consistency of a proposed 24-slot record set without treating a worker's claims, a same-host Docker grade, or an unhashed transcript as independent evidence.

`python -m tools.replanning_study_evidence --manifest <externally sealed manifest> --evidence-dir <actual authenticated records>` refuses to proceed without the preregistered twelve-task allocation and complete manifest. It preserves all 24 allocation slots, including missing and invalid records, instead of dropping unsuccessful runs or silently replacing a failure. It checks task/arm/source/fault binding, model-digest declarations, original raw request/response bytes and hashes, tool order and receipt hashes, whole-arm tool/token/wall budgets, grade trace hash, all six public/hidden grader slots and internal grade consistency.

The tool returns `NOT_ESTABLISHED_NO_INDEPENDENT_RECEIPT_ATTESTATION`, with the paired verified-completion difference **null** regardless of raw success claims. That is deliberate. To report verified success in FAR-REPLAN-001, an evaluator independent from the worker must reexecute the frozen oracle on actual permitted tool outputs, attest that the provider, isolation, interrupt placements and source bytes matched the manifest, and retain authenticated original receipts and negative outcomes. SHA-256 bindings provide tamper evidence *relative to an independently authenticated original*, not a signature or proof that bytes were executed. There is no model request in the checker.

This is not a substitute for the registered prospective launch gate, worker execution implementation, independent oracle qualification or experimental analysis. Do not combine synthetic results with real observations, pool this cohort with other FAR studies, infer causality from a `grade.success` field, or convert Codex review to external scientific independence.
