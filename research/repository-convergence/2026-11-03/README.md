It also binds the engine's `structured.py` import to the original source commit as a supplementary launcher check. The default regrades all 92 retained outputs and both SDKs' 184 metric values against the 46 source case identities and references, using only Python's standard library. It does not rerun targets or SDKs.

```sh
python -S tools/replay_convergence_comparators.py \
  --checkout /path/to/Project-FAR \
  --evidence /path/to/causal-commercial-evidence.zip \
  --output /existing/scratch-parent/fresh-regrade
```

`--evidence` also accepts the exact extracted directory. The output directory must not exist, its parent must exist, and it must be outside the original evidence directory. Symlink paths, changed sources, altered historical members, forged scores/references and missing/duplicate trials fail closed.
