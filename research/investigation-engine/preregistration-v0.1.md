Status: Research. This registration changes no accepted theory or methodology.

## Frozen evaluation rule, before new held-out runs

Compare three lanes under the same read-only retrieval policy, per-response byte
limit, request limit, wall-clock limit and native verifiers:

1. Agent: an actual pinned local model selects tool names and arguments, source
   quotations, interpretations and native verification plans. Rejected proposals
   return errors to the model. No controller substitutes a successful action.
2. Deterministic: retrieve supplied seed sources, retain exact source excerpts,
   compare dependency groups and construct bounded evidence-assessment contracts.
   It may abstain rather than invent a semantic parser.
3. Declarative: execute an explicit dependency-checked plan using the same tools.
   Its retrieval and verification work must be reported even when it matches the
   deterministic lane. The two are not assumed to be different algorithms.

An external existing research-system comparison requires an actual compatible
model/search configuration and a pinned implementation. Missing access is a
missing comparison, never a scored failure or evidence of FAR superiority.

An evaluator not given the new implementation selects eight primary-source
investigations across distinct domains. Freeze the manifest bytes and SHA-256
before execution; expose only questions, source seeds and evaluation obligations
to the runner. Selection is purposive, internal and implementation-held-out,
not population-random, answer-blind, technically isolated or externally
independent. No I2/I3 claim is permitted. Development examples and unit fixtures
are separate from these held-out records. Any post-exposure engine fix requires
a separately labeled rerun; the first failed record must remain.

## Recorded outcomes

For every lane/task preserve raw model requests and responses, tool requests and
bounded raw response bytes (including errors), exact quotations and extraction
coordinates, source dependency declarations, proposals/rejections, discovery
revisions, canonical intake validation/freeze, exact candidate hashes, native
verification inputs/outputs, synthesis and failure checkpoints. A hash binds
bytes; it does not establish truth, source independence or semantic adequacy.

Report denominators separately for attempted tasks, completed traces, validated
freezes, evaluated candidate families and correct substantive conclusions.
Completion requires real retrieval, extraction, source comparison, valid intake
freeze and all frozen candidates evaluated. Abstention can be a correct
substantive outcome, but cannot replace an unexecuted stage.

Measure quote/hash fidelity mechanically, native contract validity, unsupported
determinate conclusions, rejected tool proposals, controller substitutions,
conflict/counterexample records, HTTP/model calls, tokens, observed latency,
response bytes and missing billing/resource telemetry. Human/model semantic
adequacy judgments are separate from automated integrity checks. Cost is
unknown without actual billing evidence; local tokens are not dollars.

## Controls and interpretation

Unit/integration controls include malformed/failed/truncated responses,
credential/private/redirect destinations, source prompt injection, invented
quotations, source drift, incomplete interpretation families, frozen mutation,
premature verification, model invalid JSON, exhausted budgets, false numerical
claims, conflicting evidence and unsupported causal/normative conclusions.

The agent has no write, shell, credential, publish or consequential-action tool.
External source content is data, never policy. Source entailment judgments remain
fallible and are not turned into formal truth by quote matching. Pure arithmetic
and source-JSON comparisons may be decided only within their explicitly recorded
native scopes. FAR intake procedural conformance does not establish native
contract adequacy or evidence closure. Closure remains Incomplete unless the
accepted EC-01 through EC-11 requirements are separately satisfied.

Preserve every negative result. Do not assert general autonomy, improvement,
external independence, commercial advantage or broad reliability from this
small internal evaluation. An observed advantage, if any, is task/constraint
specific and requires an independently assessed substantive denominator.
