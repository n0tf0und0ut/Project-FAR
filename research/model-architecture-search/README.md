# FAR model architecture search — bounded research

**Status: Research.** No Accepted FAR theory, FAR reasoning engine, product, or general AI-improvement claim is changed.

## Question and justification

Can an automatic, deterministic, adaptive search among registered sequence mixers produce a candidate that generalizes better on disjoint synthetic tasks than its four fixed baselines? The existing weight-space and tool-agent studies cannot answer this architecture-comparison question. Failure is a valid outcome.

The search contains established causal attention, GRU recurrence, causal depthwise convolution, and compositions thereof. It does not generate novel primitive operations, implement arbitrary LLM-proposed code, run a large language model, or test whether any architecture replaces the Transformer.

## Prospective freeze and design

The exact protocol is protocol-v0.1.json. The experimental code and protocol were committed together on branch research/model-architecture-search-20261103 **before scored execution**, by commit b9c31ff3c380f4b4f14b16e4ed3e7dc1e7a1bddc. The runner source blob was 0a6a4d0107183c4a86478ece2b1fb8902adb4224. All later changes are documentation, tests and original evidence. The protocol SHA-256 is 22fbbf532de6b7e70bdc9c30baa590c06688d5a102fafd8ea7e5f029f6734995.

The generator selects unique length-13 binary strings: 768 train, 256 validation, 512 test. The three preregistered tasks are recall of the first bit, XOR of the first and last bits, and a strict majority of bits. No input sequence crosses splits. Every candidate uses the same embeddings, task head, training steps, optimizer and selection seed; parameter counts and training duration are explicitly reported.

First evaluate four controls (identity, single attention block, single GRU block, single causal convolution block). Use validation macro accuracy, then parameter count, then lexical recipe name to rank. Evolve four additional recipes, never returning a duplicate. Lock the winner before accessing held-out test predictions. Retrain the winner and all four controls using three fresh common training seeds. Do not retune or choose a different winner after seeing test outcomes.

This is a **steps-matched**, not FLOPs-, parameter-, wall-time- or data-distribution-matched experiment. Validation and test cases are authored and generated by the same program. Three seeds are repetitions on the same task distribution, not external replication.

## Original scored result

Eight architectures were evaluated in validation. The validation winner was two stacked causal-attention blocks, scoring 93.33% validation macro accuracy. On the held-out test set with three final train seeds, mean macro accuracy was:

| Candidate | Parameters | Mean held-out macro accuracy |
| --- | ---: | ---: |
| Identity | 354 | 55.36% |
| Single causal convolution | 1,826 | 55.36% |
| Single GRU | 3,122 | 80.16% |
| Single causal attention | 2,578 | 87.25% |
| Two stacked causal attention blocks | 4,802 | 95.76% |

The observed winner is a known stacked architecture with substantially more parameters than the single-attention comparator. It had no measured compute-matched advantage. The largest gain was on the endpoint XOR family. No new architectural primitive was discovered; no generalization beyond these authored tasks is established.

The verifier checks the frozen data split, candidate progression, validation-only selection, task count/metric arithmetic, full final-run coverage, source identity when requested, and JSON/journal integrity. It cannot prove that the original execution host was truthful or reconstruct unretained raw model predictions. External task administration, stronger scaling baselines, model-output replay, parameter/FLOP-matched controls and independent replication are required before any scientific promotion. The outcome remains Research.

## Claim boundary

Known operators assembled in a new order are not automatically a novel architecture. An architectural successor requires independently verified differences from prior designs, relevant performance and resource advantages at meaningful scale, and reproduction on external data. No such claim is made here.

## Matched-parameter replication (FAR-MAS-MATCHED-002)

The separate, prospectively frozen [v0.2 experiment](preregistration-v0.2.md) completed all 80 conditions and was source-bound and fully replayed using the recorded single-thread CPU configuration. Its [full outcome and failure-preserving evidence](RESULTS-V0.2.md) establish a **negative** primary result: the 120-step, length-15 parameter-matched contrast yielded only **+1.43 percentage points** mean macro accuracy and favored stacked attention in **2/5** seeds, missing the preregistered +2-point / 4-of-5 requirements. Secondary rankings changed with length and budget; wide attention reached 99.86% versus stacked attention's 96.40% at length 15 and 240 steps. The original v0.1 frozen experiment remains intact. Neither experiment establishes architecture novelty or general autonomous AI self-improvement.


## External-data falsification (FAR-MAS-EXTERNAL-003)

The prospectively frozen [v0.3 study](preregistration-v0.3.md) executed 96 known-mixer neural runs on two externally collected, scikit-learn-bundled UCI datasets, with 11%-bounded parameter and analytic forward-MAC proxies and three stronger non-neural reference models. Its [original results and exact nonclaims](RESULTS-V0.3.md) give a **negative primary result**: validation-selected convolution averaged 97.41% on digits versus 98.06% for RBF-SVM and 97.08% on Wisconsin diagnostic measurements versus 98.25% for logistic regression. Full deterministic same-environment replay matched 96/96 model-state fingerprints and predictions. The [complete source-bound evidence archive](archive-v0.3.zip.b64) retains the original journal, all predictions, failures, and the post-execution replay. The source-bounded archive checker is `tools/check_model_architecture_external_archive.py`.

**This is neither the official CLRS/NAS-Bench-360 benchmark, externally adjudicated science, nor a demonstrated neural architectural advantage.** The official data/reference environments were unavailable in this runtime; no claim of evaluation on those benchmarks may be made. No general AI self-improvement, architecture novelty or production FAR capability is established.
